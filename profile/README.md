PZ Wiki Modding is an organization with the goal of providing resources related to modding for the official [Project Zomboid wiki](https://pzwiki.net/wiki/Project_Zomboid_Wiki). It notably serves as the heart for the [PZ API Docs](https://pz-wiki-modding.github.io/PZ-API-Docs/index.html).

# Tools
Tools are created for modders to help them with their modding workflow.
- [ZedScripts](https://github.com/PZ-Wiki-Modding/ZedScripts) - a VSCode extension to help with the creation and validation of [scripts](https://pzwiki.net/wiki/Scripts), using the [pz-scripts-data](https://github.com/PZ-Wiki-Modding/pz-scripts-data) dataset.
- [Wiki Tools](https://github.com/PZ-Wiki-Modding/Wiki-Tools) - in-game tools for the wiki editors and modders to export renders of the character outfits and items.

# Player tools
[Wiki That!](https://github.com/PZ-Wiki-Modding/Wiki-That) is a tool to help players access wiki content directly in-game. It simply allows the player to right click an item, tile etc to easily access this element's wiki page. A tool is also provided, [PZ Backup](https://github.com/PZ-Wiki-Modding/PZ-Backup), to easily back up the current game installation to create a fully independent instance of the game to not be impacted by updates from both the game and mods.

# Datasets
Datasets are provided:
- [pz-scripts-data](https://github.com/PZ-Wiki-Modding/pz-scripts-data) - a collection of [scripts](https://pzwiki.net/wiki/Scripts) definitions
- [pz-translation-data](https://github.com/PZ-Wiki-Modding/pz-translation-data) - a collection of [translation](https://pzwiki.net/wiki/Translation) definitions
- [pz-xml-data](https://github.com/PZ-Wiki-Modding/pz-xml-data) - a collection of XML definitions for clothing files, AnimNodes etc.

# Parsers
Parsers aim to provide an automatic workflow to extract information from the game files and output useful information:
- [pz-lua-parser](https://github.com/PZ-Wiki-Modding/pz-lua-parser)
- [pz-java-parser](https://github.com/PZ-Wiki-Modding/pz-java-parser)
